A few questions

Do I need to invite a bot to every server myself?

Invite Shiftus once, then link each server as its own community from the dashboard — slash commands are available there right away.

What happens without an active subscription?

Shift types, quotas, and permissions still work — you can fully set things up first. Clocking on and logging time need an active subscription.

Where does my data live?

Everything is scoped to your community: shift history, quotas, and reports aren't visible to any other server using Shiftus.
