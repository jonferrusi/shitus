Shift tracking, built for Discord

Know exactly who's on shift, who's hitting quota, and who needs a nudge — without leaving Discord.

Clock on/off with a slash command, set weekly quotas per shift type, and get a real dashboard your admins will actually use.

Sign in with Discord Sign in with the Discord account you use on the server.

Clock on from Discord

/shift on, /shift off, or /shift manage for an interactive panel — or the same controls on the dashboard. Either one works; they share the same clock.

Quotas that fit your roster

Set a weekly quota per shift type, or one overall. Progress bars everywhere: the dashboard, the admin roster, and right in Discord when someone clocks off.

Shift types with role gates

Restrict a shift type to a specific role — only Supervisors can start a Supervisory Shift, for example — or leave it open to everyone.

A leaderboard that motivates

/shiftleaderboard shows this week's top hours, by shift type or overall, right in your server.

A few questions

Who can sign in?

Anyone who's a member of the Discord server this bot is set up on. Admin and time-logging access is controlled by roles, either from the .env file or granted in-app with /admin permissions.

Where does my data live?

In a local database on the server this bot runs on — there's no external service involved.
